Synthetic state-layer performance microbenchmark (500,000 rows):
- first visible-frame selection: about 8.45 ms
- repeated cached selection: about 0.006 ms
- first energy filtering: about 0.90 ms
- repeated cached energy filtering: about 0.008 ms

This is NOT an end-to-end GUI benchmark. Native VTK/Qt performance depends on the Mac,
GPU/OpenGL, dataset mix, network/cache state and requested rendering settings.

The complete test suite currently passes in this environment. PostgreSQL worker/admin/import
services are intentionally not part of the native desktop distribution; local DuckDB remains
the catalog, cache, and workspace store. A headless Qt Inspector
smoke test also passed; full interactive VTK camera performance still needs final
verification on the target macOS OpenGL hardware.
