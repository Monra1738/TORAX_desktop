UDON3 THEME 2 — PERFORMANCE DESKTOP BUILD
========================================

1. Open Terminal in this folder.

2. Create/activate Python 3.11 environment:

   python3.11 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip setuptools wheel
   python -m pip install -e '.[dev]'

3. Run:

   udon3-desktop

4. Fast Cas A path:
   - Search / Add observations
   - Quick target -> Cas A
   - keep ASCA + Suzaku + XRISM enabled
   - click **Load all N matching** to queue every observation returned for the target/radius
   - for the literature comparison, include ASCA 50018000 and 50018010
   - after loading, Energy -> **All events -> exact 2D image** uses every valid parquet event
   - Energy Slices -> Cas A — ASCA literature bands
   - Analysis -> Slice images to see the four bands next to one another

5. Fast SN1006 path:
   - Search / Add observations
   - Quick target -> SN1006
   - use Xtend/Suzaku for wide coverage; Resolve for detailed spectra
   - select an RA/DEC ROI in the 2D view
   - Spectrum -> Log–Log for the centre/shell comparison

6. Performance behavior:
   - loaded observations stay cached
   - mission/instrument/observation toggles do not reload parquet
   - hidden views are not recomputed
   - dragging bands/slices is debounced
   - Auto image quality and Auto spectrum bins are enabled by default

7. New spectrum / all-event behavior:
   - the raw spectrum is always preserved; Smooth curve is a separate overlay
   - Previous / Next move the selected energy band
   - Auto Scan moves it continuously and reverses at the energy limits
   - both Band Application checkboxes start OFF
   - OFF means all loaded preview events are shown in 3D and the 2D Energy image
     integrates all available preview energies
   - enable Filter 3D or Filter 2D independently when that view should follow the band

8. Detailed acceptance checks:

   docs/VERIFICATION_GUIDE.md

There is no synthetic demo and no web frontend in this distribution.
